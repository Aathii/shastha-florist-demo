# Shastha Florist — concept demo

A website concept prepared for Shastha Florist. It is a design demo, not the business's official website, and it is kept out of search engines.

Preview: https://aathii.github.io/shastha-florist-demo/

- Static site: `index.html`, `css/`, `js/`, `fonts/`, `media/`. No build step.
- Photos are the business's own public photos; hours, menu and links were read from its public listings and need the owner's confirmation.
- The opening film is AI-enhanced from photos of the premises.
